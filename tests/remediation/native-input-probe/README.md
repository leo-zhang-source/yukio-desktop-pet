# 原生输入诊断（开发用）

使用项目当前的 `QuestionPanel`、`QuestionCardLayout` 与样式构建一个单独的小窗口，不替换 Yukio，不读取真实助手记录，不连接模型，也不会向任何聊天发送答案。这个工具不是正式安装包或独立用户验收的替代品。

从项目根目录运行，输出目录每次必须新建：

```sh
python3 scripts/build-input-probe.py --out /tmp/yukio-input-probe-build
open -n /tmp/yukio-input-probe-build/YukioInputProbe.app --args /tmp/yukio-input-probe-observation
```

依次检查英文输入加中文粘贴、整体粘贴、刷新同一题、隐藏后重开，各 5 次；另做 10 次“有草稿 → 发送中 → 失败 → 继续编辑”，共 30 次。每次使用人工文字 `Yukio 你好123`，按回车仅在诊断窗口计数。文字不一致并不自动代表产品失败，应先核对输入动作。不要输入真实回答或密钥。

控制窗口和应用菜单提供下一题、刷新、模拟失败、隐藏重开与保存退出；快捷键分别为 Command-N/R/F/H、Command-2 显示问题卡、Command-Q 保存退出。发送失败是本地模拟，不连接真实接收服务。问题身份和回答通道另由自动测试中的隔离 socket 接收端核对。

日志只保存事件、题号、是否可编辑/可用、窗口与编辑器焦点、是否有未确认选词、字符数，以及与人工样例是否一致；不保存回答正文。记录具体操作、失败次数与尝试次数，并注明手工操作或界面自动操作。自动输入 Unicode/粘贴不能算真实中文输入法选词通过；必须单独记录实际输入法流程。原用户环境的偶发故障未复现时，继续保留“根因未知”。
