# 深入说明与分段回顾 · Mac 0.3.3

本轮遵循用户新增的两个入口要求。首页继续自动显示简短的“内容、解释、原因”；深入说明和过去记录只在需要时打开。原来的“解释一次／持续解释”按钮不恢复。Windows 实机测试继续由用户延后为可选，本次没有执行。

## 使用方式

1. 在桌面打开“雪绪活动工作台”，选择聊天。
2. 平时只看首页的三段短说明。点“深入解释”，展开点击时的具体做法、与前面工作的联系、用途、结果及不清楚的部分。再次点同一个按钮可收起；需要时可按最新工作重新解释。
3. 点“之前做了什么”，最近三段工作先由千问简短总结。按每次用户要求分段，最新的在上面；点“再往前看”逐页回顾，不一次铺开全部聊天。
4. 每段都有“深入看这一段”，只针对选中的一段详细说明当时的要求、助手动作和结果。展开后可再次点击收起；成功生成的说明在本页内保留，重复展开不重复调用。
5. 回顾放久了、原文后来恢复或说明失败时，可“重新读取这一页”。关闭页面后不再发起说明；已经发送的请求可能返回。

## Technical Reasoning

复用原有只读历史库、SourceContext 原文身份和行指纹验证、固定预览与 ExplanationService。新增 ReadingView，不重建采集与配对逻辑。页内授权限定精确聊天；所有新请求重新检查该页仍有效，不能通过新接口选择任意客户端、路径或其他聊天。历史跨文件只使用明确的客户端、会话、Agent 和分支身份，不按标题合并，不跨来源拼接工具执行结果。

历史分页冻结数据库快照，每页最多三段；从最多100条公开消息候选中读取有界片段，每段最多四条短摘录。优先保留本段要求和近期公开汇报，需要时补一条较早的明确要求作为背景，背景不代表已经执行。长轮次超出窗口时显示带缺失说明的工作片段，不补猜原要求。未读取内部分析；原文不写入历史数据库或普通日志。

当前深入说明与每段回顾使用各自独立的输出约定，保持首页三段的原验证规则。逐部分校验允许和必需的证据引用、文本长度、来源限定及历史时态；显示层将代码、文件路径和编号替换成普通对象名称。模型返回结构正确不代表每句话都已证实。若在长度边界留下未完成的句尾，保留前面的完整句子。

所有模式共用原有每小时调用次数、最短调用间隔和单请求互斥。回顾一页三段合并一次总结，详细说明只在点击时调用。深入输出最多1000 tokens，简短总结沿用配置预算，不切换模型或下载模型。成功结果在页内缓存；用户明确重试失败说明时不复播失败缓存，仍受预算限制。无后台历史总结队列。

## Beginner-Friendly Explanation

首页像一句简短进度播报。想知道“到底改了哪里、为什么这么改”时，再打开深入解释。想接上之前的思路时，再翻分段回顾；每次只看三段，看到需要的那段才展开。这样平时不会堆满信息，需要了解时也不用自己从整段聊天里找线索。

回顾会区分“你当时要求做什么”和“助手后来汇报做了什么”。如果只有要求、缺了答复或旧原文已经读不到，页面会说明限制，不把它写成已经做成的事。

## 核验记录

最终检查、安装与真实页面证据位于本地 `artifacts/activity-reading-0.3.3-r4/`。真实说明属于本次人工核对的样本，用户对易读性的最终感受仍待日常体验；不宣称所有聊天的解释质量、完整历史恢复、多天稳定性或 Windows 已验收。

本次为本机 Mac 交付。GitHub 公开下载仍为先前发布版，未把本地安装等同于公开发布。

**Implemented：** 当前深入解释、按要求分段的历史回顾、每段简短总结与单段展开、快照分页、页内结果保留、失败重试和页面关闭后的发送阻止。回顾标题缩短；有完整前句时去掉模型在长度边界留下的残缺句尾。等待详细说明期间维持页内连接，不同时启动首页模型生成。历史明确标出最近、更早、再早，模型不再将独立卡片写成无依据的最初／随后叙事。

**Verified：** 203项 Python 检查通过，覆盖跨文件聊天身份、其他助手隔离、分页、缺失、引用、失败重试及历史顺序。18项页面行为检查通过，含等待间隔中关页阻止下一次发送。最终独立 Mac 包核对46项运行文件，签名、无外部 Python 启动、采集和重启均通过。桌面 App、安装包与已运行服务身份核对一致；最终替换时30,471条旧 Codex 记录的内容前缀指纹一致，模型配置字节保持。当前真实开发聊天的深入说明、分段总结及单段深入说明已在实际页面生成并核对，未人工改写模型答案。

**Unverified：** 不同项目的广泛说明质量、用户日常理解感受、多天运行、Intel Mac、其他 macOS 版本、Windows 和正式签名公证。仅限当前 Mac 的包与页面验收，未重新验收原生启动窗口。

**Issues：** 解释依据来自有限短摘录，不能恢复已经消失的原文；较长轮次会分为带限制的片段。部分模型用语仍偏概括或把预期作用说得过满；引用检查不是语义真实性证明。保留“千问说明”及依据入口，不把它当作已经核实的成果。读久了可重新读取历史页；失败重试受共同调用预算限制。

**Next Steps：** 根据用户实际阅读反馈改善分段与措辞。Windows、多天体验及公开发布按后续明确范围继续，不影响本机当前两个入口使用。
