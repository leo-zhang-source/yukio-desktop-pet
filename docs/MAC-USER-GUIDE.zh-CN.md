# Yukio · 让 AI 的工作看得见

[English](MAC-USER-GUIDE.md) · [下载](https://github.com/leo-zhang-source/yukio-desktop-pet/releases/tag/v5.4-preview.1)

Yukio 是一款 Mac 桌面伙伴。它把 AI 编程助手的工作变成角色动作，用工作台解释进展，并在需要你回答时提醒你。

## 看什么

- **看状态**：读文件、写代码、运行测试，都有对应动作。
- **懂进展**：查看当前工作、原因和历史，减少来回翻聊天。
- **接住提醒**：多个聊天同时运行时，发现需要回答或已经结束的任务。

## 开始体验

1. **安装**：打开 Mac DMG，把 **Yukio.app** 拖到“应用程序”并启动。若系统拦截可信下载，在“系统设置 → 隐私与安全性”选择“仍要打开”。当前包尚未公证。
2. **打开工作台**：菜单栏小头像 →“活动工作台”（角色可见时也能右键打开）。进入雪绪设置，可更换角色、语言和大小。
3. **选择体验方式**：没有助手账号也能“播放演示”看动画；要看真实工作，停止演示，在本机 Codex、Claude Code 或 Deep Code 中开始一个任务，并开启“跟随助手活动”。

## 建议体验顺序

| 体验 | 观察重点 |
| --- | --- |
| 播放演示，再拖动角色 | 十二种动作、独立眨眼和拖动反馈；演示为模拟状态 |
| 让本机助手执行一个小任务 | 角色是否随真实活动变化，完成后如何提醒 |
| 右键角色，在工作台选择该聊天 | 查看正在发生的事、历史和解释依据 |

<a id="explain"></a>
**可选：AI 解释。** 按 [Codex](https://learn.chatgpt.com/docs/codex/cli) 或 [Claude Code](https://code.claude.com/docs/en/setup) 官方说明，在本机安装并登录自己的账号。在工作台顶部“解释交给”选择助手，再点“开启解释”。

<a id="privacy"></a>
解释会发送聊天短摘录，并使用所选助手的账号额度；不启用也能查看本机活动。

<a id="answers"></a>
**想在角色旁回答？** 开启“在这儿回答问题”，按[回答连接说明](MAC-HELP.zh-CN.md#answers)接入。批准申请由你阅读后决定。
