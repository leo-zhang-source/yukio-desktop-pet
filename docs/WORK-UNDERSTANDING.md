# 工作台：正在发生与工作解读

2026-10-29，Mac 开发候选。此次根据用户要求重组工作台，并参考既有调查；不是公开发行，也没有替换桌面正在运行的 App。Windows 按用户决定暂缓。

## 页面与用户流程

现有内容、解释、原因和交接依据统一归入“正在发生”。默认只展示最近可见活动及其状态；详细解释直接可点击，其余过程与依据在同一类中展开。结束、取消与整项工作验收保持不同含义。按用户补充要求，历史已从该折叠区移出，作为独立的“历史回顾”保留。

新增“这项工作如何推进”，可以在“这次聊天”和“整个项目”之间切换，按三个问题阅读：

1. **要达成什么目标**：保留较早明确要求与最近补充，讲清问题、希望得到的结果，以及记录中明确提出的完成条件。
2. **用什么方法与策略**：联系目标解释公开提出的做法、理由、前提和取舍，区分计划与已执行步骤。
3. **方法是否有效**：把已知结果与目标对照，说明支持到哪里、哪些仍待验证、需要哪类后续检查。操作成功、助手自述、轮次结束和操作数量都不能独自证明方法有效；不提供没有依据的评分或百分比。

打开页面与切换范围只整理本机摘要。启用自己的解释服务后，点击“解读这次聊天”或“解读整个项目”生成连贯解读；项目解读按次触发，不继承当前聊天的自动发送范围。首次未配置、登录失效、模型不可用或调用失败时，本机摘要与依据仍可查看。

四个部分各自有可点击的详细说明：当前活动展开具体工作、前后联系及用途；目标展开来源、要求变化与完成条件；方法展开公开做法、与目标的关系及前提取舍；有效性展开结果支持范围、未成立的结论及待核验方向。未启用模型时显示本机阅读说明与原始依据；这些阅读说明不冒充已生成的针对性模型分析。工作解读的每个详细面板内可单独点击“请模型进一步解释”，只发送该部分允许的有限依据，按当前聊天或项目范围生成三段深入说明。

“历史回顾”明确标为当前选定聊天的历史；选择其他聊天可回顾项目中的其他工作，不把单段聊天标成完整项目历史。每页三段，可以往前翻、回到最近，逐段展开当时要求、助手公开汇报、结果与后续，并保留记录详情入口。未启用模型时也能在本机读取历史和逐段详情；启用后使用原有按页总结与按段深入解释。缺失的记录和独立验收情况保留未知。

## 上下文与证据边界

- 聊天摘要使用当前已校验来源中开场与近期的少量公开摘录，保留明确方法与结果汇报，不读取内部思考。原来的有限读取窗口继续生效，不声称读取了完整聊天。
- 项目按当前客户端给出的项目身份或工作目录身份匹配，不按名称合并；不跨客户端猜测同一项目。此次也统一了 Codex 聊天详情与侧栏的项目身份读取。
- 每次最多纳入六段聊天，包括当前聊天与最近可读的同项目聊天；侧栏自身也有最近记录窗口。页面直接显示实际采用数量和不完整性，展开可看来源列表。这个选择入口表示项目视角，不代表全部历史已覆盖。
- 每条操作和结果仍在原聊天内配对；同属项目不证明共同目标、依赖关系或因果。项目归属变化、聊天切换、关闭页面时，过期返回不能写进新范围；发送前再次确认页面授权仍有效。
- 每段解读保留自己的引用。目标引用要求，方法引用公开方案，有效性引用结果与限制；项目范围对纳入的每段聊天保留引用要求。引用存在、格式正确不等于语义已核实，模型仍可能出错。
- 已有解读绑定它自己的资料版本与来源；记录变化时标为较早解读。纯操作记账变化不强制把解读标旧。失败时保留已有内容，不伪造模型结果，也不把无结果说成失败。
- 每个深入解释也绑定点击时的范围和来源。收起面板、切换范围、切换聊天或关闭页面后，未发出的请求不继续发送，迟到结果不能混入新范围；刷新时保留展开状态。已发出的请求仍可能返回。详情与首页、历史共用调用预算和页面授权。
- 新模块已进入便携源码包清单与运行代码指纹。包不包含本次测试记录、个人聊天、账号设置或凭据。

## 本轮验证与尚未完成事项

本机测试使用人为构造记录，未复制用户真实聊天。新增场景覆盖原目标与后续修正、早期方法保留、同名项目隔离、成员变动、六聊天上限、原文缺失、引用约束、未证实有效率拦截、授权撤回、旧结果拒收、模型失败回退和调用预算。

最初的概览候选通过 272 项 Python 检查和 39 项网页检查。补充各部分详情与独立历史入口后，在当前集成源码上以 Python 3.12.14 运行 292 项检查，全部通过、无跳过；网页逻辑 46 项通过。新增检查覆盖逐部分引用约束、无模型历史分页、关闭面板后取消发送、范围切换拒收旧回复、旧说明标记和中英文详情。便携源码候选 53 个文件的目录与 ZIP 哈希一致，隔离导入检查确认运行模块没有漏装；该包不是内置运行环境的 Mac 安装包，也不是独立用户环境验收。

本轮命令与日志保留在本地忽略目录 `YukioPlayer/build/work-understanding-20261029/`；复跑使用工作台现有的 unittest discovery 和两份 Node 网页检查。最新详情候选为 `details-reviewed-candidate/`，ZIP 的 SHA-256 为 `69ce931536250d406f242ee81a2024ad6c73a3add70111b119c7ffada298a68e`。之前的概览候选及其记录原样保留，不作为最新版本。

本机浏览器已检查模拟聊天的目标、方法、有效性、项目切换与来源展开。真实 Agent 调用在这一环境受阻：Codex 报告当前模型不支持所用登录，Claude Code 报告登录失效或尚未登录。界面保持本机摘要并显示错误；没有把模拟回复写成真实模型质量通过。

独立验收需从后续实际候选安装包开始，按公开流程使用测试用户自己的配置完成聊天解读与项目解读；记录系统、架构、包哈希、依赖、账户配置、实际结果及失败证据。用户理解检查需分别问清目标、方法为什么适用、结果支持范围及还缺什么证据，并与原记录核对；不使用主观喜欢程度或单一模型评分替代。
