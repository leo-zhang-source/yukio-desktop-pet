# Mac 操作参考与排错

[返回快速体验](MAC-USER-GUIDE.zh-CN.md) · [English](MAC-HELP.md)

<a id="version"></a>
适用于 Apple 芯片 Mac，macOS 13+。下方步骤对应 5.4 Preview 2（56）；旧版按钮和布局可能不同。

<a id="install"></a>
## 1. 安装

1. 从[下载页](https://github.com/leo-zhang-source/yukio-desktop-pet/releases/tag/v5.4-preview.2)获取 Mac DMG。
2. 打开 DMG，把 **Yukio.app** 拖到“应用程序”，再从那里启动。
3. 若提示无法验证开发者，确认下载来源可信后，到“系统设置 → 隐私与安全性 → 仍要打开”。当前包尚未公证。

启动后，菜单栏会出现小头像。角色默认在待机时隐身；可在设置中“显示雪绪”或播放演示。

<a id="first-run"></a>
<a id="follow"></a>
## 2. 开始使用

1. 点**菜单栏小头像 → 活动工作台**；角色可见时也能右键打开。
2. 点工作台右上角“设置”，选择语言、皮肤和大小。
3. 打开“跟随助手活动”，将“跟随的助手”和“桌宠跟随的聊天”设为自动。
4. 在同一 Mac 用户下打开 Codex、Claude Code 或 Deep Code，开始一个任务。雪绪读到本机活动后会自动切换动作。

可先用“播放演示”试动画，试完点“停止演示”。普通网页聊天不一定能被跟随。

<a id="explain"></a>
## 3. 开启工作解释（可选）

不配置也能看活动；想让雪绪解释工作内容，再做这一步。

1. 按 [Codex](https://learn.chatgpt.com/docs/codex/cli) 或 [Claude Code](https://code.claude.com/docs/en/setup) 官方说明，在这台 Mac 安装并登录自己的账号。普通网页登录不等于本机客户端已登录。
2. 回到工作台顶部，在“解释交给”选择该助手。
3. 点“开启解释”，选择聊天查看结果。未就绪时按页面提示处理安装、登录或版本问题。

<a id="privacy"></a>
解释会把聊天短摘录交给所选助手，使用**你自己的账号额度**。需要停止时点“停止自动解释”；关闭工作台会停止后续发送。普通用户无需配置千问。

<a id="daily"></a>
## 4. 日常操作

| 想做什么 | 怎么操作 |
| --- | --- |
| 看当前工作 | 工作台侧栏选聊天，查看“正在发生” |
| 看详细解释或历史 | 点“详细解释正在发生的事”，或展开右侧“历史回顾”；未开启解释时看本机记录；开启后，展开历史分组可按需生成总结 |
| 切换角色跟随的聊天 | 点头顶气泡展开卡片，再选聊天；恢复自动跟随可在雪绪设置中改回“自动选择” |
| 移动、缩放角色 | 拖动角色；在雪绪设置中调大小 |
| 放下完成牌 | 雪绪设置 →“取消举牌” |
| 开机启动 | 雪绪设置 →“登录时自动启动”，按提示完成系统批准 |
| 退出 | 菜单栏小头像 →“退出雪绪” |

<a id="answers"></a>
## 5. 回答问题（可选）

在雪绪设置中打开“在这儿回答问题”。这与开启解释是两项独立设置。

- **Claude Code**：菜单栏小头像 →“连接 Claude 后台回答”，完成后重启 Claude Code。
- **Codex**：需要聊天已有后台连接；无法发送时回原聊天回答。
- **Deep Code**：需要额外适配器，按菜单栏“后台回答说明”操作。

看到问题后，核对聊天名称，再选答案或输入文字。批准申请须先阅读完整内容，再选择允许或拒绝。若提示可能已发送但未确认，先查看原聊天，避免重复提交。

<a id="troubleshooting"></a>
## 6. 常见问题

| 问题 | 处理方法 |
| --- | --- |
| 找不到角色 | 菜单栏打开工作台 → 雪绪设置 →“显示雪绪／复位位置”，检查“待机时隐身” |
| 没有活动 | 停止演示、开启跟随，确认本机助手正在运行，且没有固定到其他聊天 |
| 找不到新版按钮 | 本预览版的“解释交给”在工作台顶部；角色设置在右上角 |
| 解释失败 | 先在助手自身确认登录和可用性，再检查账号额度与网络 |
| 工作台断开 | 点“重新连接”；仍失败则退出并重新打开雪绪 |
| 完成牌不自动放下 | 可手动“取消举牌”；需要自动识别聊天时，按设置提示授予实际 App 辅助功能权限 |

<a id="updates"></a>
## 7. 更新

旧版需手动安装本预览版一次。**退出雪绪 → 保留旧 App 备份 → 替换应用程序中的 Yukio.app → 重新打开**。保留原有聊天和配置，不删除用户数据目录。[详细更新与回退](MANUAL-UPDATES.md#zh)
