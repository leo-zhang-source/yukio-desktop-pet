# 用自己的 Codex 或 Claude Code 解释

工作台可以把所选聊天的短摘录交给这台 Mac 上的 Codex 或 Claude Code，用普通语言解释正在做什么、有什么用。任选一家即可，不依赖作者的千问服务，也不需要另建雪绪账号。普通用户的来源列表不显示千问；该入口仅由作者电脑的私人本机开关保留，开关与模型配置均不进入安装包。你需要自己的助手账号及相应的使用权限；解释会使用该账号的额度。

1. 打开工作台左上角「设置」，找到「连接你的解释助手」。即使还没有聊天，也能打开这里。
2. 尚未安装时，打开对应的「官方安装与登录说明」，按官方步骤在这台 Mac 安装完整客户端：[Codex](https://learn.chatgpt.com/docs/cli)、[Claude Code](https://code.claude.com/docs/en/setup)。无需安装 Yukio 的开发工具。
3. 点击「检查安装与登录」。检查只读取客户端帮助与登录状态，不发送聊天、不生成回答、不消耗模型生成额度。
4. 显示「还未登录」时，复制该卡片的登录命令，点击「打开终端」，粘贴并回车。在这台 Mac 打开的官方页面完成登录；工作台不接收密码。浏览器版工作台需自行打开 Mac 的终端。完成后回来再次检查。更换助手账号也在助手本身完成。
5. 在上方「解释交给」选择 Codex、Claude Code 或「本机 Agent（跟随聊天）」，再点「开启解释」。自动模式优先使用聊天对应的助手；未安装、未登录或版本不兼容时检查另一家。明确指定某一家时不会偷偷改用另一家。

开启后，只跟进当前所选聊天。切换聊天、关闭工作台或停止自动解释会停止后续发送；已经发出的请求可能完成。原始聊天记录仍在本机，解释按助手自己的账号与服务设置处理。发送范围、频率和额度限制在「说明与隐私」查看。解释任务独立运行，不续接、改写或向原聊天发消息。

版本不兼容时按官方说明升级；登录检查超时和读取版本超时会分别提示。检查通过仅说明已登录且客户端支持所需功能，不能保证网络、订阅余额或模型服务一直可用。服务不可用时保留本机说明和记录，可修复后重试。两家助手的检查互不影响。
