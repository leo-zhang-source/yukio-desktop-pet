5.4 Preview 1 保留桌面工作台原界面：在本机安装并登录自己的 Codex 或 Claude Code，在工作台顶部“解释交给”选择助手，然后“开启解释”。本版本不包含整改候选的安装登录卡片。

5.4 Preview 1 preserves the desktop workbench layout. Install and sign in to your own Codex or Claude Code, select it under Explain with at the top of the workbench, then Enable explanations. The separate remediation candidate's setup cards are not part of this version.

解释使用你的账号额度；未启用时仍能查看本机活动。/ Explanations use your account allowance; local activity remains available without them.
