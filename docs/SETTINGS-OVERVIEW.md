# 设置单页总览

2026-10-26：根据用户要求，移除设置中的分类切换，直接在一页展开全部设置。基于桌面正在使用的 Mac 5.3 源码修改，保留换装、聊天跟随、登录启动、更新与退出等原有操作。

- 窗口内容宽度达到 1000 点时，外观与显示、聊天与提醒、通用设置并排显示，内容使用整个窗口宽度。
- 较窄窗口按两列或一列排列，所有设置仍在同一页；高度不足时纵向滚动，不出现横向滚动。
- 下拉菜单与大小滑块随卡片宽度伸缩，长聊天标题不再撑宽页面。
- 显示／收起、复位位置、演示和完成留在同一页；设置原有回调、偏好保存与菜单刷新保护继续使用。

本次为本机界面修改，没有发布 GitHub 新版本，也没有修改或验收 Windows 版本。桌面入口继续指向用户 Applications 中的 Yukio.app。
