## 本地修复

- 正式构建与原生播放器旧构建入口读取同一更新通道配置；构建号 47 用于此次迁移候选，避免与已存在的候选 46 混淆。
- 更新列表默认安装包链接、发行说明链接使用新仓库，版本标签和文件名按 URL 路径编码。
- 生成列表前核对包内更新地址、公钥及两项强制验证设置；拒绝旧通道包或关闭验证的包，防止安装新版后再次回到失效通道。
- 备用历史项中的安装包／发行说明若仍引用旧仓库，拒绝签名；不静默改写未经核验的历史附件地址。确需保留旧兼容项时，先核对新仓库实际资产、哈希和包签名，再生成并重新签署完整列表。没有恢复的历史包不能假装可下载。
- 签名后复验列表与安装包。原公钥、Bundle ID 和签名要求不变，不以关闭验证绕过故障。
- 更正更新说明和问题清单，说明恢复原样的 v5.3 不等于迁移版。
