# Codex／Claude Code 解释接入：本地候选 48

本轮按用户「开发使用 Codex 和 Claude Code 解释的功能」继续完善普通使用者入口。仅本地开发、构建和核验，没有上传 GitHub、发布或替换主机现用 App。Windows 按用户决定暂缓。

## 功能

- 工作台设置新增两张助手卡片，提供官方安装说明、检查安装与登录、复制登录命令。Mac 内嵌工作台可直接打开终端；登录由用户在自己的电脑、官方页面完成，不收集密码，也不复制作者凭据。
- 默认使用用户自己的本机助手，保留自动跟随聊天、明确指定 Codex 或 Claude Code、自选内网模型。开启解释前检查；没有准备好时提示下一步，不妨碍本机记录。
- 打开页面只发现可执行文件。显式检查只运行已验证支持的帮助和登录状态命令，不启动模型生成。登录子命令不明确的旧客户端不猜测执行；Claude 返回格式不明时不再误报已登录。
- 两家检查分别限时、分别锁定；同一家重复检查不会叠加启动，另一家继续正常。界面延迟返回不覆盖另一张卡片或新检查结果。检查不会修改解释授权、聊天选择、额度或设置。
- 延续现有解释任务的独立调用、短摘录确认、接收方固定和聊天身份隔离。解释不会续接或向原聊天发送消息。安装后可重新检查并选择刚安装的助手，无需手工改配置文件。

普通用户操作见 [用自己的助手解释](../EXPLANATION-AGENTS.md)。官方依据：[Codex 安装](https://learn.chatgpt.com/docs/cli)、[Codex 登录](https://learn.chatgpt.com/docs/auth?surface=cli)、[Claude Code 安装](https://code.claude.com/docs/en/setup)、[Claude 登录命令](https://code.claude.com/docs/en/cli-reference)。
