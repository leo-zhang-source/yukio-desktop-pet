# 设置页绿白风格调整（本地候选 41.1）

本轮以用户正在使用的 5.4（41）、源码 `8d2deb2f` 为基础，只调整原生设置页；保留工作台、设置行为、记录、动画与账号配置。不混入另一个任务的候选 49，也不上传 GitHub。

## 设计依据

Interface Design：用户在查看工作后进入设置，目标是迅速找到角色显示、跟随聊天和系统选项。产品语境为桌面陪伴、工作进展、聊天、任务气泡、完成举牌与角色换装。颜色来自已确认工作台的雪白纸面、浅绿分区、松绿强调、深绿正文和灰绿说明。

特征是把角色的显示、跟随与提醒放在同一个工作台语境里，原生控件保留 Mac 操作习惯。避免大蓝色动作压过设置、等距堆砌和只靠标题区分白色容器。分组标题带浅绿底和系统图标，内容仍是原生表单，动作集中在底部。

组件检查点：标题 28pt／半粗、组标题 17pt／半粗、正文 14pt、说明 13pt。4pt 基础间距，页面边距 24pt，分组内容边距 20pt；分组间 16pt，页面大块间 24pt。仅细边框建立层次，不增加装饰阴影或动画。输入、开关保留系统焦点与菜单。大按钮降低到 44pt，普通动作至少 36pt；标签可换行，窄窗按 3／2／1 栏变化。

Impeccable 检查针对 AppKit 的颜色对比、可访问名称、原生控件、排版、长标题和中英文。网页检测器不能作为 Swift 原生界面的检查结论。仍须实际构建和目视检查，本地预览不能冒充独立环境验收。
