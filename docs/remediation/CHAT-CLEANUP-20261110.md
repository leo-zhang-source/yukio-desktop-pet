## 问题与修复

- 导航把工作目录当项目，同名工作树和 scratch 目录反复出现。取消推断出的项目栏和重复的最近列表，按 Codex、Claude 等客户端分开，每段聊天只列一次。工作目录不再生成项目身份；不把不同来源的同名聊天合并。
- Claude 本地记录中的 `custom-title`／`ai-title` 曾被忽略，前五条消息又常是摘要／回执。现在只读取精确来源、精确会话的名称，头尾各最多 256 KiB，忽略未完成行，随文件变化刷新有界缓存。明确名称优先，备用名称从同一份有上限的开场窗口生成，列表／详情保持一致；已有同名聊天仍保持独立。

- 新增的文字清理模块已进入实际打包清单及服务版本指纹。未改变依赖、更新源、公钥或角色素材；构建配置认可哈希已同步复核。
