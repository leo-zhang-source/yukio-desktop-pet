## 诊断使用

只在诊断一次真实问题时，退出测试副本后使用其包内程序启动：

```sh
"/path/to/Yukio.app/Contents/MacOS/YukioPlayer" --input-diagnostics "/path/to/new-input-events.jsonl"
```

路径需由测试用户选择、父目录已存在，文件必须不存在；若文件已存在或是符号链接，不覆盖、不追加。正常启动不启用诊断。记录实际输入法名称和触发前操作，结合日志确认是否为焦点、禁用状态或组合输入问题；不要求提供回答正文。日志只是诊断证据，不是故障已修的证明。
