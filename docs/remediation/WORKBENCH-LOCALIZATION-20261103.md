# 工作台界面语言修复（本机候选 41.4）

范围：同一个雪绪 App 的中英文工作台。沿用设置中的语言选择和既有绿白布局；只修复系统界面漏译、组合提示及标点。没有创建独立英语 App，没有修改 Agent 调用、提示词、登录或解释生成逻辑。本次限本机交付，不上传 GitHub。

## 修复

- 补齐活动类型、未知操作、文件操作、回执结果、阶段标记、读取范围、来源提醒以及历史回顾依据标题的英文词条。
- 修复未翻译的中文经过英文对象别名替换后形成“保存了一条the activity history”的情况。完整界面译文使用英语；无法翻译的原始文字保留原语言，不再做残缺替换。
- 界面拼接的冒号和句号随当前语言显示。聊天名称、用户原文和来源摘录保留原语言。
- 继续使用现有的设置 → 工作台语言路径，语言优先于浏览器／系统默认值；本地链接与读取请求沿用当前页面语言。界面 HTML、CSS 和原生布局未改变。

## 已完成验证

- Python：307 项，306 通过、1 项平台条件跳过。新增回归覆盖全部记录类型、工具标题、回执结果分支、组合范围说明、历史步骤占位、依据标题以及原文保护。
- 网页逻辑与语言：51 项通过。
- 原生工作台窗口：6 项通过，包括 App 设置优先、切换后刷新同一工作台、设置页语言以及选择上下文保留。
- 隔离人工记录页面：两块独立展开、详情提示、较早步骤／返回最近、完整历史页均使用英文界面；解释自动运行关闭，没有使用真实 Agent 进行生成测试。
