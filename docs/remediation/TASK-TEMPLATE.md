# 小改动记录模板

每个主题只写一次，合入后保留；不要把未知或未测填为通过。

- **问题与范围**：可复现触发、应有行为、涉及的平台和模块。
- **验收**：修前失败证据，修后检查命令／实际操作；涉及状态时注明来源、聊天数、轮次、旧回执和取消。
- **来源**：起点提交、任务分支、最终源码提交；有包时记录版本、哈希、运行路径与独立环境。
- **结果与限制**：实际结果、未覆盖场景、外部阻塞；代码／本机测试／独立验收／公开发布分别表述。
- **保存与回退**：本地及归档证据路径，恢复校验，逐主题反向提交；不覆盖测试后新增的用户资料。旧工作目录标明使用中、保留、待核实或拟退役。

本轮真实使用实例见 [性能修复](PERFORMANCE-20261101.md) 与阶段 1–5 验收总记录。模板不要求额外远端提交；只有用户明确要求上传时才集中同步。
