- Codex 结果归属：桌宠保留的 Swift / Python 实现仍有共享失败状态，不能因单元测试通过认定原报告中的交错结果问题已经消失。旧目录的相关候选和共同样例保留给阶段 2、3。

- 回答框偶发不能输入、实际更新失败：保留用户报告，根因及新版真实链路尚未验证。
- 5.3.3 独立环境记录指出正常安装启动受到系统安全检查阻拦，且正式签名、公证和真实账号生成尚未通过。该记录来自另一条正在进行的验收，不能把它当成本分支已完成验收。
- 同一业务在 Swift、Windows Python、工作台 core Python 中仍有不同实现。工作台 core 的 19 个 Python 文件只有 6 个与 Windows 同名文件完全一致；其他差异包含有意的无界面实现与版本差异，不能整体覆盖消除。

阶段 1 的 G1 判断只针对开发入口与保留关系：统一入口已经建立，当前功能源码和素材没有被无声移除，旧工作有明确保留位置。135 个旧主目录的活跃路径变体保持待核实，未擅自合并或丢弃；这不代表其逻辑已全部审查。进入阶段 2 后应优先完成它们中与已知故障有关的样例审查。
