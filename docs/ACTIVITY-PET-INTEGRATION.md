# 在雪绪里打开活动工作台

> 后续本机排版版为桌面 0.4.6 (27.3)、内置工作台 0.3.5，增加聊天侧栏和三组设置。[新版使用与核验](ACTIVITY-CHAT-NAVIGATION.md)。下文保留首次接入的构建依据。

右键点桌面雪绪（或 Control 点按），原来打开设置的位置现在打开活动工作台。菜单栏的入口改为“活动工作台…”，原快捷键 Command+, 保留。点窗口外部或点关闭按钮收起；可以拖动窗口、调整大小。

工作台顶部右侧常驻“设置”按钮。它在同一个窗口里显示原有雪绪设置，包含当前版本原有的显示、大小、聊天、换装、登录启动、检查更新和退出等选项。点“活动工作台”或设置里的“完成”返回。设置直接沿用原生回调和存储，不经网页传递，不重新创建一套偏好。

工作台嵌在 App 中，正常使用无需另开浏览器或独立工作台 App。运行时随包附带，不依赖系统 Python。原独立工作台仍可使用，两者由原启动器校验代码和数据范围后复用同一服务，不抢占其他版本的端口或停止别的启动器。

打开工作台按既有设置解释所选聊天的短摘录。切到设置时暂停页面说明，返回后接续；收起窗口后销毁页面，不留隐藏网页继续调用模型。已经发出的请求可能完成。本机记录器与页面分开：收起窗口保留活动记录，退出雪绪只停止它自己启动的服务，不结束别的程序启动的服务。详情仍见页面“说明与隐私”。

## 本机交付基础

桌面原 App 为 0.4.6 (27.1)，源码依据为 `92ea141e15f861146227f039c033b1e905f86628`。当前根目录播放器属于另一条开发线，缺少桌面版的换装与更新组件，不能直接拿它整体替换桌面版。

因此原生集成补丁同时保留在当前源码与独立构建快照中。实际安装包以桌面版本对应的源码快照构建，沿用桌面包全部 275 项原有资源与更新框架，附带已验证的工作台 0.3.4 (23) 运行时。本机集成构建标记为 0.4.6 (27.2)，不是新的公开正式版本。构建工具 `tools/activity-workbench/build_integrated_macos.py` 要求明确指定基础 App、工作台 App、编译结果和源码，输出新的目录，校验资源不变且不包含用户记录或模型配置。

## 验证

Swift 单元检查验证原有设置回调、窗口内设置布局、连接失败时仍能操作设置，以及仅允许本机工作台导航。实际网页生命周期另用 `--workbench-panel-check <结果.json>` 在真正 AppKit 事件循环中检查：工作台与设置同窗、返回原页面、关闭清掉页面、重新打开、收起不停止记录器及退出停止本程序的启动器。测试只访问空白检查地址，不发送真实聊天。

测试数据与构建记录位于 `artifacts/activity-pet-integration-20261025-r1/`。原 App 留有完整备份。Windows 的实机检查仍按用户要求留作之后的可选任务；本轮不声称已接入或验收 Windows。GitHub 发布、签名公证也不包含在这次本机接入中。
