三步开始

  1. 安装：把同目录的 Yukio.app 拖到“应用程序”，从那里启动。DMG 复制完成后可推出。ZIP 用户先解压。
  2. 试动画：右键角色打开工作台，点右上角“设置”，选择“播放演示”。可拖动、调整大小或换角色。
  3. 跟随真实工作：停止演示，打开“跟随助手活动”，在本机 Codex、Claude Code 或 Deep Code 中开始任务，再到工作台选择聊天。

首次打开若提示无法验证开发者，确认下载来源可信后，去“系统设置 → 隐私与安全性 → 仍要打开”。不要关闭系统安全保护。启动后菜单栏会出现小头像，App 通常不在 Dock 中显示。

让雪绪解释工作（可选）

  1. 按 Codex 或 Claude Code 官方说明，在这台 Mac 安装并登录自己的账号。
  2. 在工作台顶部“解释交给”选择助手，再点“开启解释”。需要停止时点“停止自动解释”。

解释会发送相关聊天短摘录，使用你的账号额度。开启后，展开历史分组也可按需生成总结。不启用解释也能查看本机活动。

常用操作

  • 找回角色：菜单栏小头像 → 活动工作台 → 设置 → 显示雪绪／复位位置。
  • 切换聊天：点头顶气泡展开卡片；恢复自动选择可在设置中修改。
  • 回答问题：开启“在这儿回答问题”。Claude Code 还需菜单栏“连接 Claude 后台回答”并重启客户端；其他来源见菜单栏“后台回答说明”。批准前先看完整申请。
  • 解释失败：先在助手自身确认登录、额度和网络；活动记录仍可查看。
  • 退出：菜单栏小头像 → 退出雪绪。

更新与保留数据

旧版需手动安装本预览版一次：退出 → 保留旧 App 和数据备份 → 替换同一位置的 App → 重新打开。不要删除聊天和配置。预览版使用独立签名更新源；稳定版不会自动转为预览版。

本包保留桌面现用工作台界面；不包含另一整改候选的全部改动。Windows 与云端 Cowork 暂缓。完整首次使用及所有环境的验收尚未结束。

Start in three steps

  1. Install: drag Yukio.app beside this file into Applications and launch it there. Eject the DMG after copying. Extract ZIP downloads first.
  2. Try the animations: right-click the companion, open Settings at the upper right, and choose Play demo. Try dragging, resizing or switching characters.
  3. Follow real work: stop the demo, enable Follow activity, start a task in local Codex, Claude Code or Deep Code, then select the chat in the workbench.

If macOS cannot verify the developer, and you trust the download, use System Settings → Privacy & Security → Open Anyway. Do not disable system protections. Yukio has a menu-bar avatar and normally no Dock icon.

Explain the work (optional)

  1. Install and sign in on this Mac using the official Codex or Claude Code instructions.
  2. At the top of the workbench, select Explain with and Enable explanations. Use Stop automatic explanations to stop.

Explanations send relevant chat excerpts and use your account allowance. With explanations enabled, expanding history groups can generate summaries on demand. Local activity works without explanations.

Everyday controls

  • Find the companion: menu-bar avatar → Activity workbench → Settings → Show Yukio / Reset position.
  • Switch chats: expand the speech bubble; restore Automatic in settings to resume automatic selection.
  • Answer questions: enable Answer here. For Claude Code, also choose Connect Claude background answers in the menu and restart the client. Other sources are covered by Background answer setup in the menu. Read the full request before approving.
  • Explanation failed: check sign-in, allowance and network in the assistant itself. Local activity remains available.
  • Quit: menu-bar avatar → Quit Yukio.

Updates and data

Older versions need one manual installation: quit → back up the old App and your data → replace the App in the same location → reopen. Keep chats and settings. This build uses a separate signed preview feed; stable users are not automatically enrolled.

This package preserves the current desktop workbench; it does not include every change from the separate remediation candidate. Windows and cloud Cowork are deferred. Complete first-run and all-environment acceptance remains unfinished.
