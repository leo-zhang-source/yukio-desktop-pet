# Yukio · See your AI at work

[简体中文](MAC-USER-GUIDE.zh-CN.md) · [Download](https://github.com/leo-zhang-source/yukio-desktop-pet/releases/tag/v5.4-preview.1)

Yukio is a Mac desktop companion. It turns coding-agent activity into character animations, explains progress in a workbench, and alerts you when your input is needed.

## What to look for

- **See activity:** distinct animations for reading files, writing code and running tests.
- **Understand progress:** inspect current work, its purpose and history without repeatedly searching chats.
- **Catch important moments:** notice questions and completed turns across multiple chats.

## Get started

1. **Install:** open the Mac DMG, drag **Yukio.app** to Applications and launch it. If macOS blocks a trusted download, use System Settings → Privacy & Security → Open Anyway. The current package is not notarized.
2. **Open the workbench:** right-click the desktop companion. Open Yukio settings to change the character, language and size.
3. **Choose your experience:** Play demo shows animations without an assistant account. For real activity, stop the demo, start a task in local Codex, Claude Code or Deep Code, and enable Follow activity.

## Suggested walkthrough

| Try | Look for |
| --- | --- |
| Play the demo, then drag the companion | Twelve animations, independent blinking and drag feedback; demo states are simulated |
| Give your local assistant a small task | Animations following real activity, followed by a completion notice |
| Right-click the companion and select that chat | Current work, history and the evidence behind explanations |

<a id="explain"></a>
**Optional: AI explanations.** Install and sign in on this Mac using the official [Codex](https://learn.chatgpt.com/docs/codex/cli) or [Claude Code](https://code.claude.com/docs/en/setup) instructions. At the top of the workbench, choose Explain with, select your assistant and Enable explanations.

<a id="privacy"></a>
Explanations send short chat excerpts and use the selected assistant's account allowance. Local activity remains available without them.

<a id="answers"></a>
**Want to answer beside the companion?** Enable Answer here and follow [connection setup](MAC-HELP.md#answers). Approval requests remain yours to review and decide.
