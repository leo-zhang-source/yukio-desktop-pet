# 第8、9步：按最新范围交付Mac试用版

2026-10-24。用户明确把全部Windows测试移为之后的可选工作。此目录记录Mac 0.3.0（构建18）的交付；旧Windows证据不改写、不删除，也不伪称新版通过。

## Implemented

- 显眼的“让千问解释这段聊天”入口，注明本机／千问显示状态和三段结果所在位置。
- 同一聊天换文件后的首页接续；只认明确身份与唯一候选，跨客户端／助手／分支或候选冲突时不自动换。切换清空旧说明并撤销发送授权。
- 内置运行环境的Mac App、自动打开页面、源码与安装包分发、使用说明和回退副本。
- 网站分开显示九步交付和之后的可选工作。

## Verified

- Mac程序170项、页面8项、网站8项检查通过，日志在本目录。
- 最终独立包检查、短时运行与重启、桌面安装、源码和下载文件的核对结果由本目录JSON记录。
- 来源窗口的旧入口确实与当前聊天具有相同聊天身份但不同记录文件；修复前保留旧选择，修复后只跟进唯一的当前入口。页面不会借用另一段Windows聊天的生成结果。

## Unverified

用户没有签字接受所有日常说明的易读性；更多真实任务和多天运行未验证。Windows全项、Intel Mac、其他macOS实机、正式签名公证均在后续可选范围。运行要求的构建检查不是旧版macOS实机结论。

## Issues

打包时先后发现开发机运行环境的最低系统要求过高，以及内置Python的安全策略文件遗漏导致重复打开失败。改用较低系统要求的运行环境，保留并一起打包原有安全策略文件，没有关闭证书校验；最终包增加重复打开验收。失败候选仅在本机保留，不发布。

模型仍可能用概括词，结构与引用检查不能保证每句话正确。用户录屏抽取的画面为黑屏与指针，无法单靠录屏判断点击过程；页面问题来自实际记录和浏览器核对，未拿黑屏当通过证据。
