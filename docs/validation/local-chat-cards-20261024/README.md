# 本机 Mac 聊天卡片修复 · 2026-10-24

基于桌面已安装 0.4.6 (27) 的源码 d0de8c13，局部修复卡片显示；本次不发布 GitHub 或 Windows 安装包。

两个本地聊天的检测与窗口显示分别验证。`updateCards` 原先把重新排版和窗口恢复都放在“卡片内容发生变化”的条件之后：内容不变时，展开点击会被跳过；已被移出屏幕显示列表的窗口也不会因 alpha 变为 1 而重新显示。

修复将内容防抖、展开状态和窗口恢复分开处理；需要时重新排版并将卡片窗口显示出来，保留原折叠入口、12 秒自动收起和隐藏设置。

新增测试通过实际 AppController、路由器和 AppKit 窗口验证：两个运行中的聊天、额外聊天入口、无内容变化时展开/收起、超时收起、隐藏窗口恢复和手动收起/显示。`before.log` 是相同测试在未修复实现上的两项失败；`after.log` 是修复后的 11 项相关检查通过。测试使用合成事件，不读写用户聊天。

桌面安装核验及备份路径见 installation.json（完成安装后生成）。
