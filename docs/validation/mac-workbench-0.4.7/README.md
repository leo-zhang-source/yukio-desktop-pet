# Mac 0.4.7 发布核验

本轮将此前桌面本机排版版同步为公开版本。功能保持聊天侧栏、项目与工作状态分类、本机搜索、三组设置及既有解释功能；正式标记为 0.4.7（28），内置工作台 0.3.5（24）。

## 已核对的开发基线

- 公开原生 Sources／Tests 与已测试的桌面源码快照逐文件一致，224 项 Swift 检查通过。
- 公开工作台与其随包 headless 依赖重跑 217 项 Python、22 项页面检查通过；网站导出与范围检查 8 项通过。
- 原生窗口生命周期 7 项、动画资源检查 13 段通过。原有 275 项资源按哈希保留。
- 旧版工作台的记录、配置、模型接收位置和原设置不进入公开安装包。
- 原签名账户已用无数据的探针验证，签名与已安装 App 的公钥一致；没有导出私钥或更换信任根。

## 最终发布检查

下载 ZIP／DMG、公开更新列表、升级替换与重新启动、实际桌面版本及保存记录的最终结论，以同版本附件 `validation.json` 和本文件后续发布记录为准。准备阶段不提前把这些项目记为通过。

Apple 芯片条件与签名使用 [Sparkle 官方发布规范](https://sparkle-project.org/documentation/publishing/)。旧通用 Mac 项仍保留；Windows 更新元数据及完整包原样转存，不新建 Windows 版本，不声明 Windows 新版测试。

## 回退与限制

旧桌面 App 和旧发布均保留。出现签名错误、包内哈希不符、工作台不能打开或记录缺失时，不继续升级／推广新包；保留失败样本，修复后重新构建并签名。已签名文件不得修改后继续沿用旧签名。

未验证范围仍包括 Windows 新版、Intel 工作台、更多 macOS 实机、多天运行和所有真实说明质量。没有声称已完成 Apple 正式签名或公证。
