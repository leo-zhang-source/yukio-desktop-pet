# Mac 0.4.7 发布核验

本轮将此前桌面本机排版版同步为公开版本。功能保持聊天侧栏、项目与工作状态分类、本机搜索、三组设置及既有解释功能；正式标记为 0.4.7（28），内置工作台 0.3.5（24）。

## 已核对的开发基线

- 公开原生 Sources／Tests 与已测试的桌面源码快照逐文件一致，224 项 Swift 检查通过。
- 公开工作台与其随包 headless 依赖重跑 217 项 Python、22 项页面检查通过；网站导出与范围检查 8 项通过。
- 原生窗口生命周期 7 项、动画资源检查 13 段通过。原有 275 项资源按哈希保留。
- 旧版工作台的记录、配置、模型接收位置和原设置不进入公开安装包。
- 原签名账户已用无数据的探针验证，签名与已安装 App 的公钥一致；没有导出私钥或更换信任根。
