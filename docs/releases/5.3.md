# Yukio 5.3 — corrected version numbering

**The current public version is 5.3**, continuing with 5.4 and 5.5; a major release moves to 6.0. The interim 1.0 label was a numbering mistake, not an intentional restart. Existing release tags are retained for history.

This keeps the verified in-app update repair: choose **Install Update** and Yukio downloads, validates, installs and reopens. Readable English/Chinese notices and existing chats/settings are preserved. The native runtime is unchanged from the 232-test verified update repair; this release corrects version metadata and documentation.

Users on **0.4.11, 0.4.12 or the interim 1.0** can use the in-app update path. Users on **0.4.13** must install the complete 5.3 app once, replacing the current copy in the same location, because that build's compiled download-page-only driver cannot be repaired by a feed. Keep one App named **Yukio**.

Apple silicon Mac, macOS 13+. Windows remains optional with its existing 0.4.6 assets unchanged. Other Macs, multi-day use and Apple notarization remain unverified. The build is ad-hoc signed. No system protections are disabled.
