# Yukio 0.4.9 · Projects and understandable context

Apple silicon Mac, including workbench 0.3.7. Windows testing remains optional.

- Projects appear above Recent chats, following the requested GPT-style arrangement. Work status is a small per-chat marker. Search, project expansion and the selected chat remain available.
- Chinese and English follow the Mac's preferred language. Reopen the App after changing that preference. Original chat titles and quoted source notes retain their original language.
- Readable explanations introduce the object and purpose, connect current work with earlier reports and omit code, filenames, paths and machine output.
- Fixes a real 0.4.8 review failure where an illustrative example was presented as actual project work. Concrete example content has been removed from writing instructions, and test/quoted material is explicitly distinguished from task facts.
- Saved chat records, model settings, pet preferences and existing update signature checks are retained.

中文：聊天选择按“项目、最近聊天”排布，工作状态只作标识。说明继续使用普通语言，并交代事情是什么、接着前面哪一步、有什么用。修复检查中发现的“把测试例子说成真实项目内容”。

Download the ARM Mac ZIP or DMG from this release, or use **Settings → More → Check for updates**. The App uses a local temporary signature and is not Apple-notarized. Intel Macs and Windows keep their earlier compatible version; no new Windows acceptance is claimed.

Validation is recorded separately after package and desktop checks. Model references and structural tests do not prove every explanation is correct or understandable. See [implementation and limits](../ACTIVITY-LANGUAGE-AND-CONTEXT.md).
