# Yukio 1.0 — candidate, not published

Public app versions now follow 1.0, 1.1, 1.2, and 2.0 for a major release. The app name stays **Yukio**. This candidate restores the existing-user **Install Update** option and readable English/Chinese update notes. A user click authorizes download, installation and relaunch; merely checking for updates does not.

**Release gate is still open:** the actual 0.4.11 old-client tests passed the install prompt, download, signature verification and extraction, but the test Mac still blocks final replacement. No successful installation or relaunch is claimed. ZIP and DMG match all 470 candidate files; the current desktop App and public release remain 0.4.13. [Verification and remaining work](../validation/mac-update-1.0/README.md).

0.4.13 users will need to install the complete 1.0 app once after it is released, because 0.4.13 was compiled with a download-page-only driver. Other supported old clients can receive the installable feed. Windows remains optional with its existing 0.4.6 downloads unchanged. This candidate is ad-hoc signed, not notarized.
