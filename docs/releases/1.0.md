# Yukio 1.0 — Install Update is back

Yukio checks for a newer version and reminds you. Choose **Install Update** and the app downloads, verifies, installs and reopens. Nothing is installed without your click. English and Chinese update notes now use readable formatting.

Public app versions use **1.0, 1.1, 1.2…**, then **2.0** for a major release. The name stays **Yukio**, with one installed copy. The integrated workbench is unchanged.

**0.4.13 users:** install the complete 1.0 app once, replacing the existing copy in the same location. That release's download-page-only code cannot be repaired by a feed. Afterward, updates work inside Yukio. Other supported old clients regain the install button directly.

A real 0.4.11 executable successfully updated to 1.0 in isolated testing. A separate simulated 1.0 → 1.1 update completed after one click; no public 1.1 is released. Both retained settings and matched all 470 target files. A corrupted update was rejected with the old app unchanged. 231 native tests and the signed-feed check passed. The unsupported sandbox-only installer setting was corrected for this non-sandboxed app.

Tested on this Mac in the user's Applications folder. If macOS requests access to your installation folder, confirm the system prompt; no security protections need to be disabled. Windows remains optional with existing 0.4.6 files unchanged. Other Macs, Intel workbench, multi-day use and Apple notarization remain unverified. The Mac app is ad-hoc signed.
