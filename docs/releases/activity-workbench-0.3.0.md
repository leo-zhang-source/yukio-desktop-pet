# 雪绪活动工作台 0.3.0 · Mac 试用版

2026-10-24。本轮按用户最新要求完成第8、9步的 **Mac 工程验收与试用版交付**。Windows 的所有后续测试移至“之后可选”，不作为本轮完成条件；过去的测试和未验证范围仍保留。独立工作台不会替换 Yukio 桌宠0.4.6。

## 怎么用

1. 下载并解压 Mac 安装包，把“雪绪活动工作台.app”放到桌面或应用程序中，双击打开。已内置运行环境，无需安装 Python。
2. 页面打开后，在“这段聊天”选择你正在关心的聊天。下面就是**内容、解释、原因**。
3. 页面上方会写明当前显示本机说明还是千问说明。点**让千问解释这段聊天**，确认显示的短摘录后，可选只解释一次或限时持续解释。生成结果直接替换本页三段文字。

Windows测试中的说明不会自动出现在Mac另一段聊天里。各自选择的聊天、说明和发送同意分别处理。没有配置模型时，仍可看本机说明、过程与依据。现有用户的配置和历史保持原位；首次使用者可按源码README配置自己的内网模型，不在包中分发任何人的地址或配置。

## 这次改了什么

- 说明按钮移到三段文字上方，明确说明结果出现在哪里，区分本机说明与千问说明。
- 修复聊天换记录文件后，旧入口一直停在较早内容的问题：只在客户端、聊天编号、助手和分支身份完全对应且只有一个候选时，跟到最新记录；不按名称猜测，不合并旧结果。
- 跟到新的记录入口会清空旧说明和发送同意，旧同意不自动扩展到新记录。
- Mac包内置独立运行环境，首次打开自动展示工作台。历史、原桌宠和回退副本保留。
- 公开网站的九步与之后的可选工作分开，Windows不再挡住本轮交付。

## 检查范围

Mac程序170项、页面行为8项、网站8项检查通过。独立包在去掉外部Python路径、中文和空格目录中检查，包含采集、保存、显示、任务与交接小结、突然退出和重启；重启前后模拟记录均为11条。还会在服务已运行时重复打开，避免独立包缺少安全资源而误报启动失败。最终包还会进行实际计时的短时持续检查、桌面文件与下载文件核对，具体数字以[交付核验记录](../validation/activity-mac-0.3.0/README.md)为准。

此前真实说明曾发现错误并修复；一次获准的Windows修正版说明通过三处旧错误和引用核对，但文字仍偏概括，用户未签字认可易读性。该记录属于历史范围，不作为新的Mac体验结论。本次不新增真实资料模型发送。

## 使用边界

- 预览包面向Apple芯片，构建目标macOS13+，实际实机检查在当前Mac完成；旧版macOS与Intel实机没有测试。
- 本地临时签名，未完成Apple开发者签名和公证。如系统拦截，请按系统提示核对来源，不关闭安全保护。
- 解释可能不准确；助手自述、所见记录和推测分别标注。请求、成功回执、任务完成和用户验收不同。
- 当前一轮工程验收结束，不表示所有解释都好懂、所有第三方客户端都完整可见，或已经证明多天稳定。
- Windows、更多真实任务、长期体验、正式签名公证与更广系统兼容留作后续可选工作。

## 架构选择说明

**Technical Reasoning：**首页可从选中记录的明确身份定位同一聊天的唯一新入口。历史证据与项目说明仍按各自范围保存；只是改变当前页选择，不把两个来源的工具结果拼在一起。切换入口时撤销旧发送授权。独立Mac运行环境使用具有较低系统构建要求的Python发行版，Swift窗口明确以macOS13为编译目标，避免把开发电脑的系统要求带给下载用户。构建方式依据[PyInstaller运行环境说明](https://pyinstaller.org/en/stable/runtime-information.html)。

**容易理解的说法：**同一本聊天换了新的记录本，页面应该翻到新本，而不是一直盯着旧页；但旧页上的结果不能随便算到新页上。运行环境一起装好，则省去用户另外安装开发工具这一步。
