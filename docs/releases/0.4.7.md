# Yukio 0.4.7 · Mac 工作台、聊天选择与设置

本轮为 **Apple 芯片 Mac** 提供桌面雪绪 0.4.7（构建 28），内置活动工作台 0.3.5（24）。

- 右键点雪绪或再次打开 App，直接进入活动工作台；点窗口外部收起。
- 聊天改为类似 GPT 的侧栏：项目、最近聊天、正在工作、未在工作，并可搜索。
- 设置位于工作台顶部右侧，分成外观与显示、聊天与提醒、更多设置。“检查更新”在更多设置中。
- 保留内容、解释、原因、深入解释和分段回顾。说明使用具体对象名称；缺少依据时保留未知。
- 列表先整理聊天名称与状态，选择后才读取完整说明。项目只分类，不合并不同聊天或工具结果。

下载 **Yukio-0.4.7-macOS-arm64.dmg** 或 **Yukio-0.4.7-macOS-arm64.zip**。已有版本可在 App 中检查更新。已有聊天记录、模型配置和桌宠设置保留；包中没有私人聊天、API 配置、密钥或本机项目说明。新安装未配置模型时仍可查看本机说明；模型说明需要用户配置接收位置与相应授权。

Mac 更新列表与更新 ZIP 继续使用原有 Ed25519 签名，验证后才安装，不关闭安全检查。新版本号高于本机 27.3，更新列表通过 Apple 芯片条件避免推给 Intel，并保留 0.4.6 的通用项。更新机制依据 [Sparkle 的发布文档](https://sparkle-project.org/documentation/publishing/)。

**Windows 新版全部测试继续留作之后可选。** 本次没有发布 Windows 0.4.7；该版本附带的 Windows 更新元数据与完整更新包原样沿用 0.4.6，只为保持旧更新入口可用，不能当成新版测试。Windows 首次下载和 Intel Mac 仍使用 [0.4.6](https://github.com/leozhang8654/yukio-desktop-pet/releases/tag/v0.4.6)。

已通过的功能基线为 217 项工作台、22 项页面、224 项原生源码、7 项原生窗口和 13 段资源检查。独立包可在无外部 Python 的路径运行。下载、签名、实际升级、桌面版本与文件哈希的最终结果见 [本轮验证](../validation/mac-workbench-0.4.7/README.md) 与发布附件 `validation.json`。

未新增其他 Mac、Intel、多天稳定性、广泛说明质量或 Windows 实机结论。本机临时签名不等于 Apple 开发者签名或公证；不要求关闭系统安全机制。

## 重建范围

本轮原生源码包含已验证的桌面版基础与局部改动，没有将另一条开发线的播放器整体覆盖到桌面版。原资源沿用 0.4.6。

1. 在 Apple 芯片 Mac 上运行工作台的 Python／页面测试与 `swift test --package-path YukioPlayer`。
2. 使用 `tools/activity-workbench/build_macos.py --out <新目录>` 生成内置运行环境的工作台。
3. 编译 `YukioPlayer` 的 release 可执行文件。将已核验的上一版 `Yukio.app`、新工作台、编译结果及 `YukioPlayer` 源码目录传给 `build_integrated_macos.py`，明确指定 `--version 0.4.7 --build-number 28 --source-revision <精确提交>`。输出目录必须不存在，原 App 不会被修改。
4. 对新 ZIP 与更新列表运行 `scripts/make_appcast.py`，使用本机钥匙串，指定 `--hardware arm64` 和已验签的旧 `--fallback-feed`。发布前验证新包、签名、版本与历史保留；不要分发开发检查目录或测试密钥。

发布标签和应用内来源记录对应本轮确定的构建提交；后续仅补充验证文档时，分别记录文档提交，不冒充重新构建。
