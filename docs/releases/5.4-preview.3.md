# Yukio 5.4 Preview 3

**Mac arm64 · 5.4（63） · Workbench 0.4.14 · 预览版 / Prerelease**

## 本次更新

- 聊天按 Claude／Codex 等助手直接分组，默认折叠；隐藏无可读内容的空聊天，搜索和切换保持所选聊天。
- 依据 Claude 桌面客户端的明确关联合并回退前后记录，修复一个聊天被拆成多条、名称异常及图片包装残留。
- “解释交给”选择立即保存，重开保留；选择失败或生成中无法切换时明确提示。关闭解释时切换来源不会开启解释。
- Codex 短解释在本次子进程中限制过高的推理强度，减少超时，保留用户全局模型、账号及配置。
- 整理问题卡身份、草稿、旧回执和读取性能；加入完整测试清单、证据绑定、依赖登记与恢复演练入口。
- 包内 Python 更新至 3.12.16，使用固定的公开归档与 SHA-256；角色素材保持不变。

公开版本汇集本地 57–62 版，63 版增加发布元数据、指南和运行时安全更新。执行同提交两遍完整回归、实际 DMG／ZIP、签名、下载与运行版本核对；实际结果和首次失败统一记录在[交付记录](../remediation/RELEASE-54-PREVIEW3.md)。

**完整独立首次使用验收仍暂停，尚未完成。** 本包临时签名、未 Apple 公证；最低 macOS 13、Intel、完整自动升级与真实多客户端长时间交互仍未完成验收。Windows 与云端 Cowork 按用户决定暂缓。5.3 稳定版继续保留；本次只更新预览频道。

## Changes

- Show chats directly under collapsed assistant groups and hide empty chats without readable content.
- Use explicit Claude Desktop associations to keep rewound records in one chat; clean titles and attached-image wrappers.
- Save the explanation provider immediately and retain it after reopening. Changing a provider does not enable disabled explanations; failures and busy states are visible.
- Bound excessive reasoning effort only in the Codex explanation subprocess to reduce timeouts, preserving global configuration and account selection.
- Improve question identity, drafts, stale responses and source reading; add maintenance checks, evidence binding and recovery exercises.
- Bundle Python 3.12.16 from a pinned public archive. Character assets are unchanged.

This release consolidates local builds 57–62. Build 63 adds release metadata, guides and the runtime security update. See the [delivery record](../remediation/RELEASE-54-PREVIEW3.md) for the actual two-pass regression, package, signature, download and installed-version results.

**Independent first-run acceptance remains paused and incomplete.** Ad-hoc signed, not notarized; minimum macOS, Intel, complete automatic upgrades and long-running multi-client GUI acceptance remain unverified. Windows and cloud Cowork are deferred. Stable 5.3 remains available; only the preview channel changes.
