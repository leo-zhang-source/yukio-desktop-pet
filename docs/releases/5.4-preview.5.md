# Yukio 5.4 Preview 5（66.8）

2026-11-21 · Mac arm64 · 工作台 0.4.17

- 修复双屏下透明系统浮层导致已显示的聊天无法自动放下完成牌；锁屏和休眠屏幕不算已读。
- Claude 桌面版轮末提示明确标记为阻塞且带提问时，举问题牌并在工作台显示“等待你回答”；下一步建议仍按本轮完成处理。看见聊天不会自动放下问题牌。
- 设置 → 通用设置可选择“常驻窗口”或“快速查看”，互斥选择并自动保存。常驻窗口保留 macOS 绿色按钮的原生全屏；切换方式保留页面和草稿。
- 工作台聊天名称右侧新增“打开这条聊天”，尝试打开对应 Claude 桌面版或 Codex 聊天。普通浏览器、演示数据和 Deep Code 不提供此入口；只有终端记录的聊天可能无法跳转。
- 更新中英文首页、上手说明、包内离线指南和更新记录。

本版整理自桌面现用 66.7，66.8 是发布构建号；角色素材与工作台后端版本保持一致。维护线 67–69 的 Claude/Codex 生命周期候选源码单独保存，未进入本次下载包。

这是预览发布：临时签名、未 Apple 公证；本版实际聊天跳转、前台全屏/显示切换及完整独立首次使用验收仍未完成。后台控件与网页桥接检查不能替代真实客户端验收。Windows 与云端 Cowork 按用户决定暂缓。实际检查、下载与安装结果见[交付记录](../remediation/RELEASE-54-PREVIEW5.md)。

English: Fixes completion signs hidden behind transparent system overlays; distinguishes Claude blocking questions from optional next steps; adds saved Keep open / Quick view workbench modes, native fullscreen, and an Open this chat button. Actual chat switching, foreground interaction and complete independent first-run acceptance remain pending; Windows and cloud Cowork are deferred.
