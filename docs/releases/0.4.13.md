# Yukio 0.4.13 · Update notices and manual downloads

Apple silicon Mac; workbench remains 0.3.9.

Update checks now remind you of a new version and offer **Open download page** or **Later**. Download the complete Mac app, quit Yukio, then replace the existing copy in the same location. Chats and settings are stored separately. Yukio does not download, install, quit or restart itself for an update.

The previous in-app replacement flow could stall. It has been removed from the current update interaction rather than reported as a repaired installer. The signed release feed marks this release informational so compatible older Sparkle clients also open the release page. The new driver cancels unexpected downloads and refuses old install/relaunch callbacks. Automatic-check opt-out and the six-hour schedule remain; signed feed/archive checks and system protections are retained.

232 native checks passed, including five manual-update cases. Two isolated signed-feed trials displayed the new notice: Later preserved the running app; Open download page opened the official GitHub release in the default browser. Neither trial requested the update archive or changed the running version. ZIP, DMG and desktop App were checked against the same source and all 470 files matched. Original private history and configuration were retained.

[Manual update guide](https://github.com/leozhang8654/yukio-desktop-pet/blob/main/docs/MANUAL-UPDATES.md). Windows testing remains optional and its 0.4.6 files are unchanged. Other Macs, Intel workbench support, long-term use and Apple notarization remain unverified. This build has a temporary local signature, not Apple notarization.
