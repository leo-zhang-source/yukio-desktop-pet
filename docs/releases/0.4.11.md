# Yukio 0.4.11 · Complete English workbench presentation

Apple silicon Mac, including workbench 0.3.8.

- Choosing English in Yukio now also selects English for the workbench header, settings and page. Changing the choice retains the selected chat. With no saved app choice, the workbench follows the Mac’s preferred language.
- Translate dynamic status and result notes, task/handoff recap limits, errors and generated placeholder chat names, as well as static buttons. Standalone startup messages and App display names also have English text.
- Generated model explanations and history headings must be English in English mode. Mixed-language answers are rejected with an English fallback.
- Actual chat/project names and quoted source wording keep their original language, as requested. The current request and project brief are labelled as original text. Saved records and model/pet preferences are retained.

## Verification and limits

232 backend, 28 page and 227 native checks passed, along with 13 resource checks and seven native window lifecycle checks. The portable runtime passed isolated checks without system Python, including restart and handoff/recap checks. One bounded real-chat LAN-model case produced three English paragraphs; this does not prove every explanation will be correct or readable.

On the delivery Mac, a separate desktop App named **Yukio English** was installed to retain the original App while the existing replacement problem is deferred. All 470 App files match the package. The native English header and controls opened; the final full native page review is blocked by a macOS Screen Time limit on the local page. No system restriction was changed or bypassed.

Use the complete ARM Mac ZIP or DMG for this update. **Automatic checking and prompting are separate from installation after confirmation**: the latter remains unaccepted on the test Mac and is deferred. The 0.4.10 installer candidate is not included.

This build uses a local temporary signature and is not Apple-notarized. Intel and Windows retain 0.4.6; new Windows testing remains optional. See [English presentation details](../ACTIVITY-ENGLISH-COMPLETENESS.md).
