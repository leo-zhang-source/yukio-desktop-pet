# Yukio 5.4 Preview 1

**Mac arm64 · 5.4（55） · 工作台 / Workbench 0.4.7 · 预览版 / Prerelease**

## 本次更新

- 保留现用桌面工作台的布局、历史回顾和角色设置。
- 改进 Codex 桌面客户端发现与兼容回退，使用用户自己的 Codex／Claude Code 解释工作。
- 解释预览固定接收助手，保留失败原因；普通用户不显示作者私人模型。
- 更新中英文 GitHub 首页与简明指南；DMG 和 ZIP 附带离线 `Start Here.html`。
- 将包内更新地址迁入新仓库的独立签名预览源。旧版需手动安装一次。

## What's new

- Preserves the current desktop workbench layout, history review and companion settings.
- Improves Codex desktop client discovery and compatibility fallback; explanations use your own Codex or Claude Code.
- Pins the explanation recipient at preview time and retains useful failure reasons. Private author model options are excluded from normal installations.
- Refreshes the English/Chinese project pages and quick guides; DMG and ZIP include offline `Start Here.html`.
- Moves this build to a separate signed preview feed in the new repository. Older versions need one manual installation.

## 使用与验证范围 / Scope

本包基于已实际使用的 host 41.6 产品线，不把整改候选 54 的不同界面和全部修复混称为已合入。候选线继续保留。Windows 与云端 Cowork 暂缓。

This package follows the host 41.6 product line. The separate remediation candidate 54's different UI and complete fix set are not claimed as included. Windows and cloud Cowork remain deferred.

包为临时签名、未公证，仍是预览。历史独立 Mac VM 的助手调用证据见[41.6 记录](../remediation/HOST-AGENT-41.6.md)；本次包和公开下载核对见[交付记录](../remediation/RELEASE-54-PREVIEW1.md)。局部通过不代表最低系统、Intel、所有客户端或完整首次使用已验收。

The App is ad-hoc signed and not notarized. Prior independent Mac VM assistant evidence is in the [41.6 record](../remediation/HOST-AGENT-41.6.md); current package and public-download checks are recorded in the [delivery record](../remediation/RELEASE-54-PREVIEW1.md). Partial checks do not establish minimum-OS, Intel, all-client or complete first-run acceptance.
