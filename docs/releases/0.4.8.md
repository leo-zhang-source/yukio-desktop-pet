# Yukio 0.4.8 · Language and clearer explanations

For Apple silicon Macs, with workbench 0.3.6 included.

- The workbench follows the Mac's system language, with Chinese and English interfaces and explanations.
- Code, filenames, locations and program output are kept out of the readable work explanation. Supporting records remain on the computer.
- Context and purpose have more room: explanations introduce what the thing is for, connect it with earlier reported work, and describe how the step helps the task.
- Existing chat records, Qwen configuration and pet preferences are preserved.

中文说明：工作台跟随系统显示中文或英文。说明会先交代事情是什么、做什么用，再讲前面做到哪里、这一步为什么有用；不再把程序返回和文件名称直接放进正文。旧聊天记录、千问设置和桌宠偏好保留。

Download the Mac ARM ZIP or DMG from this release, or use **Settings → More → Check for updates** in the App. After changing the macOS preferred language, reopen the App. Original chat names and source quotations keep their own language.

Windows tests remain optional; this release carries the unchanged 0.4.6 Windows update assets for compatibility. Intel Macs retain the earlier compatible release. No new Windows or Intel workbench acceptance is claimed. The Mac build uses a local temporary signature and is not Apple-notarized.

Implementation and limits: [language and context](../ACTIVITY-LANGUAGE-AND-CONTEXT.md). Test and installed-package results are recorded in the release attachment `validation.json` when final verification completes. The existing update signature checks remain enabled.
